🔍 Scan qualité des données
Détecte les fiches avec données manquantes ou incohérentes (CP/Département, Code NAF, Catégorie, Téléphone)
🏭 Enrichissement Code NAF + Catégorie
Vérifie/force le Code NAF et la Catégorie via le SIRET (source fiable) sur toutes les fiches qui en ont un — remplit aussi les fiches sans NAF par recherche nom en repli
🧹 Détection doublons
Détecte les fiches en double (même SIRET ou même nom) — la suppression reste toujours manuelle, tu choisis laquelle garder.
🔑 Nettoyage doublons SIRET (groupé)
Regroupe les fiches par SIRET identique — un groupe à la fois. Clique une fiche pour la réparer via Recherche magique, puis passe au groupe suivant.

🔧 Réparation SIRET (temporaire)
Cible les fiches sans SIRET mais avec un Département renseigné. Recherche l'établissement correspondant au bon CP/département — remplit automatiquement si un seul candidat clair, sinon propose une liste à valider manuellement. À supprimer une fois la réparation terminée.
🗑️ Vider le SIRET d'une fiche (temporaire)
Tape le nom exact ou l'ID de la fiche dont le SIRET est faux (ex: hérité par erreur du siège) — confirmation demandée avant suppression, action réservée à ce cas de réparation.
🏢 Gestion manuelle Siège / Est Siège
Corrige manuellement le badge "Est Siège" ou le rattachement au siège d'une fiche précise.
🧹 Nettoyer les MAJ de l'historique
Retire toutes les entrées "[MAJ...]" de la colonne Commentaires (visible vendeur) — garde uniquement les notes manuelles. L'historique technique complet reste dans "Commentaire technique", rien n'est perdu.
🔧 Réparer les dates d'appel avec heure
Corrige les fiches où "Date appel" contient encore une heure collée (ex. "16/09/2026 11:12") suite à un bug du bouton "Appel effectué" rapide — ces appels étaient invisibles dans les compteurs du Dashboard. "Date appel" retrouve un format propre (JJ/MM/AAAA) et l'heure est déplacée dans la colonne "Heure appel", rien n'est perdu.
🔀 Trier le fichier maître par ID
Trie toutes les fiches par ordre d'ID (numérique, ligne d'en-tête inchangée) — utile pour repérer visuellement les doublons dans la feuille Google.
⚠️ Zone dangereuse
Ces actions sont irréversibles. Utilise avec précaution.
